# Security and privacy

Please report security issues privately to the repository owner instead of posting private dictations, credentials, keys or audio in public issues. Do not include your full profile or history database.

Audio is processed locally. Optional cloud formatting sends text only after opt-in. API keys are stored in macOS Keychain. Model downloads are pinned by the bundled manifest. Public beta packages are locally signed, not Apple-notarized.

For ordinary bugs, include app version, macOS version, the affected app, steps to reproduce and a non-sensitive example. Screenshots should hide personal information.
