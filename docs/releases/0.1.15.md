# AInauten Voice 0.1.15, Build 19

## Deutsch

- Nach einer Unterbrechung der globalen Tastenerfassung werden bereits losgelassene Diktier-Tasten wieder freigegeben. Normale Tastendrücke werden danach nicht versehentlich verschluckt.
- Noch gedrückte Diktier-Tasten behalten ihr bisheriges Verhalten. Zwei Regressionstests decken beide Fälle ab, einschließlich deaktivierter Kürzel.

Einstellungen, Wörterbuch und Verlauf bleiben erhalten. Automatische Updates verwenden die bestehende Signatur. Diese Beta ist weiterhin lokal signiert und nicht Apple-notarisiert; die bisherigen Sicherheitsgrenzen bleiben bestehen.

## English

- After global keyboard capture is interrupted, dictation keys that have already been released no longer cause subsequent ordinary key events to be swallowed.
- Dictation keys that are still physically held retain their existing behavior. Two regression tests cover both cases, including disabled shortcuts.

Settings, dictionary and history are preserved. Automatic updates use the existing signing identity. This beta remains locally signed and is not Apple-notarized; existing security limitations remain unchanged.
