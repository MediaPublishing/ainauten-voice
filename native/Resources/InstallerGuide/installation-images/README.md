# Screenshots für die Installationsanleitung

Unveränderte deutschsprachige macOS-Sequoia-Beispiele von Apple. Der dort angezeigte Name „Beispiel-App“ wird in der Anleitung ausdrücklich erklärt; die Bilder zeigen keine Aufnahme von AInauten Voice.

- Anleitung und Bildquelle: https://support.apple.com/de-de/102445
- `macos-warnung.png`: https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/locale/de-de/macos-sequoia-app-not-opened-could-not-verify-free-from-malware.png
- `dennoch-oeffnen.png`: https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/locale/de-de/macos-sequoia-system-settings-privacy-and-security-open-app-anyway.png

`package_dmg.py` bettet beide PNGs in das Offline-HTML ein. `site/build.py` kopiert sie für die Web-Anleitung.
